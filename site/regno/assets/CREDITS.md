# Crediti asset 3D

Modelli di **Kay Lousberg** — www.kaylousberg.com — licenza CC0 (pubblico dominio, uso commerciale consentito).

- KayKit: Medieval Hexagon Pack 1.0 — edifici, natura, oggetti (`kit.json`)
- KayKit: Adventurers Character Pack 1.0 — personaggi animati (`Knight`, `Mage`, `Rogue_Hooded`, `Barbarian`)

Fonte: https://github.com/KayKit-Game-Assets

Elaborazione: modelli scelti uniti in un unico file, personaggi ridotti a 7 animazioni e senza armi, poi convertiti in glTF JSON con dati incorporati (formato servito dalle anteprime claude.ai).

## Audio
`coro.mp3`: generato per questo progetto (nessun campione di terzi) con meSpeak (GPL, solo come strumento) + pyworld; script in `scripts/audio/`.
